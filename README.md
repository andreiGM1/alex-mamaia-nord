# Aura Mamaia Nord — Apartament de Lux (Alex Bălășoiu)

Website de prezentare și rezervare directă în regim hotelier pentru apartamentul de vacanță din Mamaia Nord.

## Cum rulezi proiectul
- **Vizualizare Imediată:** Fă dublu-click pe `index.html` pentru a deschide site-ul direct în browser.
- **Hosting Gratuit:** Poți încărca fișierele (`index.html`, `styles.css`, `app.js`) pe Cloudflare Pages prin Drag & Drop și este live în 30 de secunde pe HTTPS.
- **Integrare Next.js:** Dacă dorești să rulezi într-o aplicație Next.js, componenta React este disponibilă în `page.tsx`.
